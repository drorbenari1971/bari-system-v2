# בריא – טופס "הזמנה חדשה": קליטת לקוח והפקת קבלה ב-Morning

הקוד והתיעוד של טופס **"הזמנה חדשה"** במודול "ניהול לקוחות" של מערכת **בריא**.
הטופס קולט לקוח (חדש או קיים), הזמנה ותשלום, ומפיק **קבלה** ב-[Morning (חשבונית ירוקה)](https://www.greeninvoice.co.il/) דרך ה-API הרשמי.

> הריפו הזה מכיל רק את חלקי הטופס. הם תלויים בשאר מודול ניהול הלקוחות (החיבור ל-Morning, מסד הנתונים, התור וה-Audit), שנמצא בריפו [bari-system](https://github.com/drorbenari1971/bari-system), ולכן הקוד כאן לא רץ לבד.

## מה הטופס עושה
1. **לקוח:** לקוח חדש נוצר ככרטיס לקוח ב-Morning. לקוח קיים בלי כרטיס מקבל כרטיס ונשאר אותו לקוח.
2. **הזמנה:** שורות מהקטלוג של Morning, או שורות חופשיות. הסכום מחושב אוטומטית.
3. **תשלום:** Bit, PayBox, העברה, מזומן, אשראי או אחר. הסכום שווה להזמנה. מספרי כרטיס וחשבון בנק לא נשמרים.
4. **קבלה:** תצוגה מקדימה (בלי ליצור כלום), אישור מפורש, והפקה. שליחה במייל רק אם מסמנים.

## מניעת קבלה כפולה
- **מפתח הזמנה:** לכל טופס יש מפתח ייחודי, ושליחה חוזרת מחזירה את אותה הזמנה.
- **שמירה לפני כל קריאה:** ההזמנה נשמרת לפני כל קריאה ל-Morning. השלבים: טיוטה ← לקוח נוצר ← בהפקה ← הופקה, נכשלה או לא ודאי.
- **בלי ניסיון חוזר לקריאות שיוצרות:** אחרי תקלת רשת או שגיאת שרת לא מנסים שוב, כי ייתכן שהרשומה כבר נוצרה. הזמנה כזו מסומנת "לא ודאי".
- **"בדיקה ב-Morning":** הזמנה לא ודאית נבדקת לפני כל ניסיון נוסף.
